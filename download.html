Opening it the first time — this is normal ✅

SemantiNote is a brand-new app, so it isn't code-signed by Apple/Microsoft yet. Your computer may show a one-time security warning — it's not a virus, just an unrecognized new publisher. Here's how to open it (you only do this once, then it opens normally forever):

🪟  Windows

If you see “Windows protected your PC”:

  1. Click More info
  2. Click Run anyway

🍎  macOS

If you see “can’t be opened… unidentified developer”:

  1. Right-click SemantiNote and choose Open
  2. Click Open again in the pop-up

Still stuck? System Settings → Privacy & Security → scroll down → Open Anyway.
