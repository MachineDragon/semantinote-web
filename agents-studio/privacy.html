Privacy Policy

Agents Studio keeps your agents and chats on your computer

Last updated: October 31, 2026

The short version: Agents Studio has no accounts and no tracking. The AI runs on your own computer, and your chats, agents, tools, memory notes and keys stay on your device. The app only goes online when you use something that needs the internet — like downloading a model, web search, reading a web page, a cloud model or an MCP server you add — and to check for updates.

Who we are

Agents Studio is an app made by SemantiNote. In this policy, "we" and "us" mean SemantiNote. This policy applies to the Agents Studio desktop app for Mac and Windows. This website is covered by the SemantiNote Privacy Policy.

No account, no tracking

You don't create an account to use Agents Studio, and we don't ask for your name, email or payment details. The Agents Studio app contains no analytics, advertising or third-party tracking code.

AI processing on your device

By default, Agents Studio runs open-source AI models on your own computer with its built-in AI engine, or with your existing Ollama if you have it. Your messages, your agents' replies and the conversations inside a team are processed locally and are never sent to us.

Data stored on your device

Your chats, agents, teams, tools, MCP server settings, long-term memory notes, chat checkpoints and settings are stored only on your computer. They are never sent to us. Uninstalling the app and deleting its data folder removes them.

Secrets Vault

API keys you add to the Secrets Vault are stored in your operating system's secure keychain. A key is given only to the tools you choose, and is sent only to the service that tool talks to. We never receive your keys.

What goes online — only when you use it

AI model downloads. When you pick a model, it is downloaded from Ollama to your computer. These requests share only the standard information any internet request carries (such as your IP address).

Web search. When an agent uses the web search tool, the search words are sent to Ollama's web search if you've added an Ollama API key, or otherwise to DuckDuckGo.

Web pages. When an agent reads a web page, that page is fetched directly from its website.

Ollama Cloud models. If you add your own Ollama API key and choose an Ollama Cloud model, the messages and context for that request are processed by Ollama under Ollama's privacy policy. If you only use models on your computer, nothing is sent to Ollama's cloud.

MCP servers and your own tools. MCP servers you connect and Python tools you add can send data wherever they are designed to. What they do is up to the people who made them — only add ones you trust.

Automatic updates. Agents Studio checks GitHub for new versions and downloads updates from there. These checks share only the standard information any internet request carries (such as your IP address and the app version), and are handled by GitHub under its own privacy policy.

Third parties

The outside services Agents Studio talks to are Ollama (model downloads, and — only with your key — web search and cloud models), DuckDuckGo and the websites an agent reads (only when an agent uses those tools), GitHub (updates), and any MCP servers or tools you add. We don't sell, rent or share your data with anyone, and we don't receive it in the first place.

Data retention and deletion

We don't receive or keep any of your data, so there is nothing for us to retain or delete on our side. You can remove keys from the Secrets Vault at any time, and uninstalling Agents Studio and deleting its data folder removes everything it stored.

Children

Agents Studio isn't directed at children under 13 and doesn't knowingly collect information from anyone.

Changes and contact

If this policy changes, the new version will be posted on this page. See also the Terms of Use. Questions: semantinotesupport@gmail.com.
