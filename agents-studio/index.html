Features

Everything you need to build agents.

Create agents

Give each agent a name, a role and instructions, and a model. Not sure where to start? An AI helper can draft an agent from a one-line description.

Give agents tools

Built-in tools — web search, read web pages, run Python code, calculator and time — plus your own Python tools. An AI helper can draft a tool for you too.

Require approval

Optional: turn on “require approval” and the agent asks before running a tool. You choose Approve or Reject.

MCP servers

Connect MCP (Model Context Protocol) servers to give your agents even more tools.

Team chats

Group chat with a manager, round-robin, sequential, parallel, handoff or Magentic — or chat with one agent, or straight with a model.

Secrets Vault

API keys are stored in your computer’s secure keychain and given only to the tools you choose.

Memory & checkpoints

Long-term memory notes your agents can use. Save a chat checkpoint and restore it later.

FAQ

Questions, answered.

Is Agents Studio free?

Yes — Agents Studio is free. There’s no account to create and no card to enter. Just download it and start building.

Is my data private?

Yes. There’s no account and no tracking, and your chats, agents and keys stay on your computer. Agents Studio only goes online when you use something that needs it — like web search, reading web pages, or cloud models. See the privacy policy for the details.

Do I need Ollama?

No. Agents Studio has a built-in AI engine, so there’s nothing else to install. If you already use Ollama, Agents Studio can use your models.

Which AI models can I use?

Open-source models such as Qwen 3.5, Llama, Mistral and DeepSeek-R1, running on your own computer — you choose which ones to download (2–8 GB). With your own Ollama API key you can also use Ollama Cloud models.

Is it safe to let agents run code?

Agents and tools can run code on your computer, so only add tools and MCP servers you trust. For extra safety, turn on “require approval” so an agent asks before running a tool, or have agents run code in an isolated process or a Docker container (needs Docker Desktop). And remember: AI output can be wrong — check anything important.

What powers Agents Studio?

Agents Studio is built on Microsoft Agent Framework and Ollama.

Where are my API keys kept?

In the Secrets Vault, which stores them in your computer’s secure keychain. A key is only given to the tools you choose.
